# Certification Hub

A simple public website for keeping all certifications in one place.

## Customize

1. Open `index.html` and update the name, initials, and profile line if needed.
2. Open `certifications.js` and replace the sample certifications with your own.
3. Put certificate PDFs or images in `certificates/`, then use paths like `certificates/my-certificate.pdf` for `credentialUrl`.

## Run locally

Open `index.html` in a browser, or run a local server:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish

You can host this free on GitHub Pages, Netlify, Vercel, or Cloudflare Pages.
